# Gelir-Gider Tablosu

Basit gelir ve gider kayıtları tutan PHP örneği.

## Chrome'da aç

Bu bilgisayardaki PHP sunucusu çalışıyorsa [Gelir-Gider Tablosu'nu aç](http://localhost:8000/gelir-gider.php).

Bağlantı yalnızca PHP sunucusu bu bilgisayarda çalışırken açılır. Sunucu kapalıysa, XAMPP PHP ile bu klasörde bir terminal açıp şu komutu çalıştır:

```powershell
C:\xampp\php\php.exe -S localhost:8000 -t .
```

Sonra Chrome'da `http://localhost:8000/gelir-gider.php` adresine git.
